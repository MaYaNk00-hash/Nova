# NOVA Desktop Companion — Release Notes

## Version 0.1.0-alpha (Initial Standalone Desktop Release)
**Release Date**: November 15, 2026  
**Architecture**: Windows x64 (Self-Contained .NET 8 WPF)  
**Package**: `NovaSetup-0.1.0-x64.exe`

---

### Highlights & Key Features

1. **Independent Windows Application Experience**:
   - Packaged with Inno Setup 7 as an independently installable Windows application.
   - Zero external runtime prerequisites: .NET 8 x64 runtime is completely self-contained.
   - Start Menu integration, optional Desktop shortcut, and registered Windows Uninstaller in Settings.
   - Standard user privilege operation (`asInvoker`) requiring no administrative access for daily use.

2. **Refined Floating Dynamic Island**:
   - Centered docking at the top screen edge with Per-Monitor V2 DPI awareness.
   - **Compact Notch Mode**: Displays only the enlarged robot chassis and luminous cyan eyes. Clean, focused, and distraction-free.
   - **Circle Bubble Mode**: Ultracompact, translucent circular widget that minimizes screen footprint while keeping companion presence active.
   - **Expanded HUD Bar**: Full dashboard featuring media playback controls, calendar, clock, system performance graphs, and workspace tools.
   - **Workspace Slide Views**: Tabbed navigation between HUD overview, Notes, Tasks/To-Dos, and Tools.

3. **Robot Companion with Cursor Tracking**:
   - Metallic robot head chassis ($50 \times 46\text{ px}$) with glass visor and dual neon cyan gaze pupils.
   - Continuous 30fps hyperbolic tangent cursor tracking across the entire monitor canvas.
   - Context menu toggle to enable or disable cursor tracking on demand.
   - Reactive gestures: idle floating hover, blinking, and affirmative nodding upon user interaction.

4. **Synchronized Windows Media Player Controls**:
   - Direct integration with Windows Global System Media Transport Controls (GSMTC).
   - Real-time track metadata: Title, Artist, Album, and High-Resolution Thumbnail extraction.
   - Specialized recognition for YouTube Music, Spotify, Apple Music, Edge, and Chrome sessions.
   - Synchronized timeline progress tracking with interactive scrub bar (click or drag to seek).
   - Media transport actions: Play / Pause toggle, Skip Next, and Skip Previous.

5. **Local-First Notes & To-Do Storage**:
   - Persistent storage located in `%LOCALAPPDATA%\Nova\Storage\`.
   - Notes and task lists are preserved across restarts and application upgrades.
   - Offline, local-first architecture with zero telemetry or forced cloud dependencies.

6. **System Tray & Windows Startup Integration**:
   - Single-instance enforcement via named Mutex with IPC wakeup signaling.
   - Minimize-to-tray capability with custom system notification area menu.
   - Optional automatic launch at Windows startup managed via `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

| Component | Implementation |
|---|---|

| Test Coverage | 73 automated tests covering models, services, IPC, and UI controllers |

### Verified Limitations (Phase 5 Disclosure)

- **External Windows Toast Notification Capture**:
  In accordance with Windows 10/11 platform privacy architecture, external notification capture (reading toast notifications generated by other third-party apps via `UserNotificationListener`) requires a registered UWP/MSIX package identity with explicit user notification permission granted in Windows Settings. 
  In the current unpackaged Win32 distribution mode, external notification capture is restricted by the OS security boundary. All internal NOVA events, reminders, timers, and scheduled notifications operate with 100% functionality.
